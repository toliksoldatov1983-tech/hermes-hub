# Правила AI-провайдеров

- Основной провайдер: Gemini.
- Запасной провайдер: DeepSig / DeepSeek V4 Pro.
- Ключи нельзя хранить в проекте.
- Ключи должны подключаться через переменные среды Windows.
- Gemini используется первым.
- Если Gemini недоступен, лимит закончился или произошла ошибка, допускается переключение на DeepSeek.
- Если оба провайдера недоступны, работа останавливается и пользователю пишется отчёт.

На текущем этапе API не подключаются и ключи не создаются.
