# Правила Codex

- Работать крупными блоками.
- Не трогать запрещённые зоны без отдельного разрешения.
- Не удалять и не перемещать старые данные без отдельного разрешения.
- После каждого блока обновлять состояние, DONE, NEXT_TASK и REPORT_TO_USER.
- Не завершать работу без следующего крупного шага.
