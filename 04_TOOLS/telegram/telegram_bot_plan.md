# План Telegram-бота

- Telegram-бот будет будущим рабочим входом в Гермеса.
- Сначала только dry-run режим.
- Live-режим только после отдельного разрешения пользователя.
- Бот не должен менять файлы, удалять данные, запускать команды или работать с реальными заказами без подтверждения пользователя.

На текущем этапе Telegram не подключается и live-бот не запускается.
