# Цикл проверки кода

Codex пишет код.

Codex запускает проверки.

DeepSeek проверяет код.

DeepSeek пишет замечания.

Codex исправляет критичные замечания.

Codex повторно запускает проверки.

После двух циклов — финальный отчёт пользователю.

DeepSeek не должен напрямую менять файлы проекта.

DeepSeek только проверяет и пишет замечания.
