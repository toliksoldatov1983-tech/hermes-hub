# OPERATOR ROOT INPUT TEMPLATE

Для будущего controlled real-folder copy укажите точный путь:

```
ROOT_READY:
<путь к корню заказов>
```

Примеры:

```
ROOT_READY:
E:\Заказы
```

```
ROOT_READY:
D:\Заказы
```

Важно:
- Не выполнять этот шаблон сейчас
- Это только заготовка для будущего
- Путь должен быть валидным и доступным на момент preflight
