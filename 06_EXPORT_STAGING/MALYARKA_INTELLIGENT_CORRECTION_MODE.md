# MALYARKA INTELLIGENT CORRECTION MODE

## Правило

Пользователь **НЕ обязан** писать точное слово «Правка».
Hermes распознаёт correction mode по смыслу фразы.

## Trigger Phrases

Любая из этих фраз включает correction mode:

- "исправь", "поправь", "не так", "я имел в виду"
- "у нас это называется", "считай так", "запомни"
- "в дальнейшем понимай так", "дальше так и понимай"
- "это не фрезеровка", "это просто раскрой"
- "мыло — это прямой фасад", "это относится к..."
- "в этом заказе сделай так", "эта группа деталей..."

## Алгоритм Hermes в Correction Mode

1. **Определить ЧТО исправляется:**
   - термин / тип фасада / тип работ / операция
   - группа деталей / материал / цвет / толщина
   - фрезеровка / примечание / правило на будущее

2. **Определить ОБЛАСТЬ:**
   - только текущий заказ
   - текущий заказ + правило на будущее
   - только терминологическое правило

3. **Исправить** текущий заказ

4. **Пересобрать** preview

5. **Разделить** confirmed / disputed rows заново

6. **Проверить** gates заново

7. **Если disputed = 0** → разрешить staging, но real export только по workflow

8. **Если disputed > 0** → final export BLOCKED, показать спорные места

9. **Если правка постоянная** → сохранить через /learn, обновить skill

10. **Если правка неоднозначная** → спросить только спорный момент

## Примеры

### Пример 1: Терминология
> "Нет, мыло — это не фрезеровка, это просто прямой фасад."
- Correction mode ON
- Термин «мыло» = тип фасада модерн/прямой
- Операция зависит от типа работ
- Для покраски: без ЧПУ
- Для под ключ: раскрой + покраска
- Сохранить правило

### Пример 2: Группировка
> "В этом заказе фасад выборка относится ко второй группе."
- Исправить группировку текущего заказа
- Пересобрать preview
- Не сохранять правило (не сказано «запомни»)

### Пример 3: Постоянное правило
> "У нас всегда фасад модерн — это прямой фасад без профильной фрезеровки."
- Применить к текущему заказу
- Сохранить как постоянное правило
- Обновить skill

### Пример 4: Короткая правка
> "Исправь это."
- Смотреть последний спорный момент
- Если контекст понятен → исправить
- Если непонятно → спросить коротко «что именно?»

### Пример 5: Операция
> "Это не фрезеровка, это просто раскрой."
- Фрезеровка = без фрезеровки
- Примечание = раскрой

## Scope Decision

| Фраза пользователя | Область |
|-------------------|---------|
| «в этом заказе» | Только текущий |
| «всегда», «у нас», «запомни», «в дальнейшем» | Постоянное правило |
| «дальше понимай так» | Постоянное правило |
| Без указания scope | Текущий заказ |
