# Решения проекта

## Принятые решения

- Hermes-Clean является новым источником правды.
- Старые проекты и архивы не являются рабочей правдой.
- Gemini выбран основным AI-провайдером.
- DeepSig / DeepSeek V4 Pro выбран запасным провайдером и ревизором кода.
- Telegram-бот рассматривается как будущий рабочий вход, но live-режим запрещён без отдельного разрешения.
