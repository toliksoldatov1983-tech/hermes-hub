# Правила памяти

- В Hermes-Clean записывается только проверенная актуальная информация.
- Старые ошибки и старые решения не считаются актуальными без подтверждения.
- Источник каждой важной перенесённой информации должен быть понятен.
- Реальные заказы и персональные данные не заносятся без отдельного разрешения.
