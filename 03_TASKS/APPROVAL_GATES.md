# APPROVAL_GATES

1. `APPROVE_GOOGLE_DRIVE_MOVE` — переносить файлы Google Drive.
2. `APPROVE_GOOGLE_DRIVE_REAUTH` — переподключать Google Drive / расширять OAuth.
3. `APPROVE_SECRET_SETUP` — работать с ключами, токенами, `.env`.
4. `APPROVE_TELEGRAM_LIVE` — запускать live Telegram.
5. `APPROVE_REAL_ORDER_ACCESS` — работать с реальными заказами.
6. `APPROVE_MALYARKA_ARCHIVE_IMPORT` — импортировать Malyarka archive.
7. `APPROVE_DELETE` — удалять файлы.
8. `APPROVE_ARCHIVE_UNPACK` — распаковывать большие архивы как рабочие проекты.
