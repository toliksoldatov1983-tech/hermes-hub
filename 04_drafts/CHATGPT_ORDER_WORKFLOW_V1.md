# ChatGPT: рабочая система заказов — версия 1

## 1. Главный принцип

Создать **один проект ChatGPT** с названием:

`ПРОИЗВОДСТВО — ЗАКАЗЫ`

Внутри проекта держать:

- постоянные справочные файлы и общие правила;
- постоянные специализированные чаты по этапам;
- отдельный управляющий чат для каждого реального заказа.

Не вести весь заказ в одном чате. Не создавать отдельный проект на каждый заказ. Единицей передачи между чатами является **Карточка заказа**.

## 2. Какие чаты создать

Создавать в таком порядке:

1. `00 — ДИСПЕТЧЕР И ШАБЛОНЫ`
2. `01 — ЗАКАЗ [НОМЕР] [КЛИЕНТ]`
3. `10 — ФОТО И РАЗМЕРЫ`
4. `20 — КАЛЬКУЛЯЦИЯ`
5. `30 — EXCEL И ДОКУМЕНТЫ`
6. `40 — ЗАДАНИЕ ДЛЯ COREL`
7. `50 — ЗАДАНИЕ ДЛЯ МАЛЯРКИ`
8. `60 — ФИНАЛЬНАЯ ПРОВЕРКА`

Чаты `00`, `10`–`60` постоянные и используются для разных заказов. Чат `01` создаётся новый для каждого заказа, например:

`01 — ЗАКАЗ 2026-014 ИВАНОВ`

## 3. Что делает каждый чат

### `00 — ДИСПЕТЧЕР И ШАБЛОНЫ`

Назначение:

- принять хаотичное описание новой работы;
- создать номер и Карточку заказа;
- показать, каких данных не хватает;
- подсказать следующий чат;
- хранить чистые версии шаблонов.

Не делает точное распознавание размеров, калькуляцию и производственные документы.

### `01 — ЗАКАЗ [НОМЕР] [КЛИЕНТ]`

Это главный журнал одного заказа.

Здесь хранятся:

- актуальная Карточка заказа;
- решения и изменения клиента;
- результаты всех специализированных чатов;
- текущий статус;
- список готовых и недостающих документов.

Любой результат из чатов `10`–`60` возвращается сюда. Только этот чат собирает итоговую версию заказа.

### `10 — ФОТО И РАЗМЕРЫ`

Назначение:

- разобрать фотографии и эскизы;
- выписать видимые размеры, подписи, количество деталей и особенности;
- разделить точные данные, предположения и неразборчивые места;
- подготовить структурированный блок для Карточки заказа.

Важно: размер нельзя считать точным по одной фотографии без масштаба, линейки, известного эталона или подписи. Такой размер помечается `ОЦЕНКА`, а не `ФАКТ`.

### `20 — КАЛЬКУЛЯЦИЯ`

Назначение:

- проверить исходные размеры и количество;
- рассчитать площадь, периметр, расход, количество элементов, туров и другие показатели;
- показать формулы и промежуточные значения;
- пересчитать заказ после изменения параметров;
- сравнить старую и новую версии.

Чат не должен придумывать формулы, коэффициенты, цены и нормы. Их нужно загрузить как справочник.

### `30 — EXCEL И ДОКУМЕНТЫ`

Назначение:

- сформировать таблицу заказа;
- создать нужные Excel-файлы по утверждённым шаблонам;
- проверить названия листов, столбцы, единицы и итоговые формулы;
- подготовить ведомость документов.

В этот чат передаётся только проверенная Карточка заказа и утверждённый расчёт.

### `40 — ЗАДАНИЕ ДЛЯ COREL`

Назначение:

- сделать однозначное техническое задание для оператора CorelDRAW;
- перечислить детали, габариты, количество, контуры, отверстия, подписи, слои и требования к файлу;
- выделить неясности, мешающие отрисовке или резке.

ChatGPT может подготовить ТЗ и проверить структуру данных. Возможность создать готовый `.cdr` нужно проверять отдельно; безопаснее считать итогом этого чата точное ТЗ для Corel.

### `50 — ЗАДАНИЕ ДЛЯ МАЛЯРКИ`

Назначение:

- подготовить производственный лист;
- указать детали, количество, площадь, цвет, систему покрытия, стороны окраски, подготовку поверхности и примечания;
- не допускать в работу позиции с неизвестным цветом или неподтверждённым объёмом.

### `60 — ФИНАЛЬНАЯ ПРОВЕРКА`

Назначение:

- сравнить Карточку заказа, расчёт и все документы;
- найти расхождения в размерах, количестве, площади, цвете и версиях;
- дать решение `ГОТОВО`, `НЕ ГОТОВО` или `ГОТОВО С ОГОВОРКАМИ`;
- составить короткий список исправлений.

## 4. Инструкция проекта ChatGPT

Вставить этот текст в настройки проекта:

```text
Ты работаешь внутри проекта производственных заказов.

Главное правило: не выдумывай размеры, количество, материалы, цвета, цены, нормы, формулы, сроки и решения клиента. Неизвестное помечай НЕТ ДАННЫХ. Предположение помечай ПРЕДПОЛОЖЕНИЕ. Данные с фото без надёжного масштаба помечай ОЦЕНКА.

Каждый заказ имеет уникальный ID и одну актуальную Карточку заказа. Во всех результатах обязательно указывай ID заказа и версию карточки. Не смешивай данные разных заказов.

Работай по этапам:
ПРИЁМ -> ФОТО/РАЗМЕРЫ -> КАЛЬКУЛЯЦИЯ -> EXCEL -> COREL -> МАЛЯРКА -> ФИНАЛЬНАЯ ПРОВЕРКА.

Специализированный чат выполняет только свой этап. После этапа всегда выдавай БЛОК ПЕРЕДАЧИ, который можно целиком скопировать в управляющий чат заказа.

Если входных данных недостаточно, не продолжай расчёт как будто всё известно. Сначала перечисли критические вопросы. Не задавай повторно то, что уже есть во входной карточке.

Для любых чисел указывай единицы измерения. Показывай формулы и промежуточные расчёты. При изменении заказа увеличивай номер версии и перечисляй отличия от предыдущей версии.

Пиши по-русски, коротко и структурно. В конце ответа всегда указывай:
СТАТУС ЭТАПА:
ЧТО ГОТОВО:
ЧЕГО НЕ ХВАТАЕТ:
СЛЕДУЮЩИЙ ЧАТ:
```

## 6. Стартовый промпт для нового заказа

Вставлять в `00 — ДИСПЕТЧЕР И ШАБЛОНЫ`:

```text
Создай новую Карточку заказа из моего сообщения. Ничего не выдумывай. Заполни известное, неизвестное пометь НЕТ ДАННЫХ. Сначала задай только критические вопросы, без которых нельзя определить состав заказа. Затем выдай карточку V1 и текст, который я должен вставить в новый управляющий чат заказа.

Мои данные:
[сюда можно надиктовать имя клиента, изделие, квадратуру, количество, туры, срок и всё остальное в любом порядке]
```

## 7. Промпт для управляющего чата заказа

Первым сообщением в новый чат `01 — ЗАКАЗ ...`:

```text
Ты управляющий журнал только этого заказа. Ниже исходная Карточка заказа.

Твои задачи:
1. Хранить одну актуальную версию карточки.
2. Принимать БЛОКИ ПЕРЕДАЧИ из специализированных чатов.
3. Не смешивать этот заказ с другими.
4. При каждом изменении создавать следующую версию V2, V3 и далее и перечислять изменения.
5. Показывать готовность этапов и следующий нужный чат.
6. Не выполнять специализированный этап вместо соответствующего чата.

[вставить Карточку заказа V1]
```

## 8. Универсальный промпт специализированного этапа

Его можно использовать в чатах `10`–`60`, меняя название этапа:

```text
Выполни этап: [ФОТО И РАЗМЕРЫ / КАЛЬКУЛЯЦИЯ / EXCEL / COREL / МАЛЯРКА / ФИНАЛЬНАЯ ПРОВЕРКА].

Работай только с заказом [ID]. Используй приложенные файлы и карточку ниже. Не меняй исходные данные молча. Все найденные противоречия вынеси отдельно. Если критических данных нет, останови этап и перечисли вопросы.

[вставить актуальную Карточку заказа]

В конце выдай:
1. РЕЗУЛЬТАТ ЭТАПА.
2. ПРОВЕРКУ.
3. НЕЯСНОСТИ.
4. БЛОК ПЕРЕДАЧИ ДЛЯ ЧАТА ЗАКАЗА — самостоятельный текст с ID заказа, версией входа и всеми изменениями.
```

## 9. Как реально провести один заказ

1. Надиктовать заказ в чат `00` и получить карточку V1.
2. Создать чат `01 — ЗАКАЗ [ID] [КЛИЕНТ]`, вставить карточку.
3. Если есть фотографии — карточку и фото отправить в чат `10`.
4. Скопировать его БЛОК ПЕРЕДАЧИ обратно в чат заказа; получить новую версию карточки.
5. Актуальную карточку отправить в `20`, результат вернуть в чат заказа.
6. После подтверждения расчёта последовательно пройти `30`, `40`, `50`.
7. Все итоговые документы и актуальную карточку проверить в `60`.
8. Решение из `60` вернуть в управляющий чат заказа и закрыть заказ только при статусе `ГОТОВО`.

## 10. Какие файлы положить в проект

Сначала достаточно 5–7 эталонных файлов:

1. `01_Правила_расчёта` — формулы, коэффициенты, округление.
2. `02_Справочник_материалов_и_цветов`.
3. `03_Шаблон_Excel_заказ`.
4. `04_Образец_правильного_Excel`.
5. `05_Требования_Corel`.
6. `06_Шаблон_задания_малярке`.
7. `07_Один_эталонный_закрытый_заказ` — без лишних персональных данных.

Не загружать десятки старых заказов общей кучей: модель может смешивать похожие значения. Для каждого активного заказа прикладывать только его исходники и в тексте всегда указывать ID.

## 11. Что ещё нужно выяснить для версии 2

Чтобы сделать точные, а не общие промпты, нужны:

- один реальный пример входящего заказа;
- один набор исходных фотографий;
- действующие формулы калькуляции и правило расчёта туров;
- перечень всех Excel-файлов и обязательных столбцов;
- пример задания или файла для Corel;
- пример документа для малярки;
- один полностью правильно выполненный старый заказ как эталон.

После этого общие чаты можно превратить в конкретную производственную линию с точными шаблонами и проверками.
