# Закреплённые правила оформления заказов

Заказ № 002 «Юля, фасады, выборка 90 градусов» использовать как эталон для следующих заказов.

## Общая работа с заказом

1. Сначала распознать весь заказ, собрать спорные строки и получить подтверждение только по неоднозначным данным.
2. После уточнений пересчитать заказ полностью, а не исправлять отдельные итоги вручную.
3. Разделять детали по цветам и типам обработки отдельными блоками.
4. Для каждого заказа хранить исходные фотографии, итоговый Corel-файл, файл малярки и краткую карточку заказа.
5. Не плодить версии на рабочем столе: изменять или заменять файл с тем же именем.
6. Если целевой файл открыт и пользователь в данный момент им не пользуется, сохранить изменения, закрыть только этот файл и заменить его новой версией.

## Файл для Corel

1. Содержит только сухие размеры деталей: высота, ширина, количество.
2. Данные начинаются со второй строки.
3. Никаких примечаний, площадей, стоимости или технологических пояснений.
4. Детали разделяются по цветам; внутри заказа сохраняется понятное разделение выборки, модерна и витрин.

## Файл для малярки

1. Отдельные страницы или блоки по цветам.
2. Указывать тип, высоту, ширину, толщину, количество, площадь одной детали, общую площадь строки и только необходимые примечания.
3. Показывать общее количество деталей и общую площадь заказа.
4. Показывать отдельные итоги площади по выборке, модерну и витринам.
5. Каждая размерная строка остаётся отдельной; количество и площадь должны быть проверяемыми формулами.

## Покраска и примечания

1. По умолчанию красится одна лицевая сторона; это не повторять в примечаниях.
2. Торцы не входят в площадь и отдельно не упоминаются.
3. Минимальный обкат выполняется по умолчанию и в таблице не указывается.
4. Пометку «без обката» переносить только когда она явно есть в заказе.
5. Обратную сторону не считать и не описывать, кроме явно указанного подкраса или полной двухсторонней покраски.
6. Стандартная короткая формулировка: «Подкрас с обратной стороны: 100 мм по одной длине».
7. Если сторона подкраса не указана, подкрас выполняется по любой одной стороне.
8. Для витрин сохранять технологические параметры выборки под стекло: сторона выборки, глубина и отступ от наружного края.

## Квадратура и стоимость

1. Площадь детали: высота × ширина / 1 000 000.
2. Площадь строки: площадь детали × количество.
3. Торцы в квадратуру не включаются.
4. Текущие ставки эталонного заказа: модерн — 26 000 ₸/м², выборка 90° — 33 000 ₸/м², витрина — 35 000 ₸/м².
5. В итоговом листе отдельно показывать стоимость работ, стоимость ЛКМ и сумму «работы + ЛКМ».

## Нормы расхода ЛКМ

1. Краска для модерна и выборки — 0,300 кг/м².
2. Грунт для модерна — 0,300 кг/м².
3. Грунт для выборки — 0,600 кг/м².
4. Для витрины в заказе № 002 применено 0,300 кг/м² краски и 0,600 кг/м² грунта как для выборки. Отдельная постоянная норма витрины ещё не подтверждена.
5. Цена краски — 12 000 ₸/кг; цена грунта — 5 000 ₸/кг, пока пользователь не сообщит новые цены.
6. Источник норм должен быть указан в итоговом документе.

## Контроль качества

1. Перед выдачей сверить количество, квадратуру по строкам, группам, цветам и общий итог.
2. Проверить формулы на ошибки и визуально просмотреть все страницы.
3. После замены итогового файла сравнить контрольные суммы рабочей и архивной копий.
4. Не подменять последнее подтверждение пользователя ранним черновиком или предположением.
