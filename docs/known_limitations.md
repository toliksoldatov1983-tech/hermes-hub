# Known Limitations — Hermes-Clean Release Candidate v2

## 1. Отсутствие реального экспорта

| Проблема | Детали |
|----------|--------|
| Экспорт в CorelDraw | Не реализован. `build_export_model()` возвращает структуру, но не создаёт .xlsx |
| Excel-генерация | Убрана при адаптации из malyarka-clean (зависимость от openpyxl) |
| Решение | Использовать `build_export_model()` для получения данных, затем external скрипт |

## 2. Заморозка Google Drive

| Проблема | Детали |
|----------|--------|
| Google Drive API | Полностью заблокирован `GDriveStub`. Любые операции → 403 |
| Sync-папки | Симуляция `sync_folder()` всегда падает с ошибкой |
| Freeze | После первой попытки retry невозможен до `unfreeze()` |
| Решение | Использовать `gdrive_manual/` — ручное размещение файлов |
| Разблокировка | Требует `register_pending_approval(ms)` → `ms.approve()` администратора |

## 3. Только эмуляция Telegram

| Проблема | Детали |
|----------|--------|
| Telegram API | Не используется. `telegram_flow.py` — чистый эмулятор |
| Нет реальной отправки | `show_final_report()` возвращает строку, не отправляет |
| Нет webhook'ов | Обработка входящих сообщений не реализована |
| Решение | Для продакшена — интеграция через Hermes Gateway |

## 4. Отсутствие персистентности

| Проблема | Детали |
|----------|--------|
| Task Queue | Состояние хранится в памяти. Нет save/load в JSON |
| Memory Sync | После перезапуска Python — все решения теряются |
| Dialog Flow | История сообщений не сохраняется между сессиями |
| Решение | Добавить `to_dict()` / `from_dict()` и save в JSON (планируется) |

## 5. Синтетические данные

| Проблема | Детали |
|----------|--------|
| Фикстуры | 11 штук, все синтетические. Нет проверки на реальных заказах |
| Pricing | 150 руб/м² — жёсткая константа. Нет кастомизации |
| Disputes | Только 7 шаблонов. Реальные причины могут отличаться |
| Решение | Добавлять фикстуры по мере поступления реальных кейсов |

## 6. Нет интеграции с AI-моделями

| Проблема | Детали |
|----------|--------|
| AI Provider | MockProvider возвращает `[MOCK]` ответы |
| Нет реальных LLM | Весь код работает на хардкод-логике |
| Решение | Через Hermes Gateway подключить реального провайдера |

## 7. Отсутствие CLI

| Проблема | Детали |
|----------|--------|
| Нет `hermes`-подобного CLI | Все компоненты вызываются из Python |
| Нет скриптов запуска | Нет `.bat` / `.ps1` лаунчеров |
| Решение | Текущий BATCH_081 не включает CLI (планируется отдельно) |
