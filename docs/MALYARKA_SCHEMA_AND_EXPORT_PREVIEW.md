# MALYARKA_SCHEMA_AND_EXPORT_PREVIEW

This is the local schema for future Malyarka order data and export preview.

## Command

```cmd
scripts\hermes.cmd malyarka-schema
```

## Safety

The schema is synthetic and local. It does not write Excel files, read real orders, read old archives, read Google Drive or touch secrets.

Real export remains gated until a future explicit approval.
