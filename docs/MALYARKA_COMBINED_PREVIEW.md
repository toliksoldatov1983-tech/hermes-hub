# Malyarka Combined Preview

## Назначение

`malyarka-combined` объединяет локальный разбор заказа, классификацию спорных строк и synthetic pricing в одном выводе.

Команда безопасная:

- не читает файлы заказов;
- не читает клиентские документы;
- не импортирует архивы;
- не пишет Excel;
- не использует реальные цены;
- не запускает внешние сервисы.

## Команда по умолчанию

```cmd
scripts\hermes.cmd malyarka-combined
```

Без аргументов используется встроенный synthetic пример.

## Команда с ручным тестовым вводом

```cmd
scripts\hermes.cmd malyarka-combined "paint | 2 | bucket"
```

Переданный текст считается ручным тестовым вводом, а не реальным заказом.

## Правило безопасности

Даже если preview готов, команда не может писать файл и не может использовать результат как реальный заказ.
