# Эталонные заказы Малярки

Эти документы перенесены из локальной выгрузки Google Drive и используются только как проверочные сценарии логики.

## Правила использования

- Эталон не является действующим заказом.
- Исторические цены внутри эталона не применяются к новым заказам.
- Перед расчётом нового заказа цены, нормы ЛКМ, закупочные цены и ставки работ берутся из текущих реестров.
- Если эталон конфликтует с текущими правилами Hermes-Clean, действуют текущие правила.
- Файл `YULYA_001.md` содержит исторический реальный пример; не использовать как тестовые персональные данные в публичных отчётах.

## Сценарии

1. `YULYA_001.md` — одна группа и двухсторонняя позиция.
2. `UCH_002.md` — пять групп, маршрут «Фрезеровка + покраска».
3. `UCH_003.md` — пять групп, маршрут «Покраска», без Corel.
