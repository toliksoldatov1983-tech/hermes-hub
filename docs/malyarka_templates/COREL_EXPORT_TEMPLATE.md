# Шаблон Corel-файла Малярка

## Когда формируется

- `Фрезеровка + покраска` — формируется.
- `Покраска` — не формируется, если пользователь отдельно не запросил.
- При спорных строках финальный файл не формируется.

## Формат

- первая строка пустая;
- заголовков нет;
- далее только три значения через табуляцию: `Высота`, `Ширина`, `Количество`;
- только подтверждённые позиции.

Пример:

```text

720	496	2
920	446	3
```

## Объединение

Только в Corel-файле строки с полностью совпадающими высотой и шириной могут объединяться, количество суммируется. В остальных документах исходные строки не объединяются автоматически.

## Контроль

- высота, ширина и количество заполнены;
- порядок высота/ширина не переставлен;
- спорных строк нет;
- материал, цвет, обработка и примечания в Corel-файл не попадают.
