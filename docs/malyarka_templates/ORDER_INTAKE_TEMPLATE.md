## Обязательные поля

Шапка: тип заказа, номер заказа, имя клиента, дата.

Позиция: высота, ширина, количество, материал, толщина, цвет, тип обработки, статус.

`Изделие` и `Зона` переносятся, если присутствуют во входных данных. Отсутствие этих полей само по себе не создаёт спор, если строка однозначно относится к заказу.

## Правила

1. Первое число — высота, второе — ширина, третье — количество.
2. Каждая исходная строка сохраняется отдельно; объединение допускается только в производственном Corel-файле.
3. Все примечания переносятся без потери смысла.
4. Белый цвет без уточнения — H91.
5. Неясное значение помечается `⚠️` прямо в соответствующей строке; указывается номер строки.
6. Пока есть хотя бы одна спорная строка, запрещены финальные площадь, цена, материалы и экспорт.
7. После исправления спорных данных заказ пересобирается полностью.
