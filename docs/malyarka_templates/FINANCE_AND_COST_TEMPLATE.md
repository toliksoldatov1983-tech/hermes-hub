# Шаблон финансов и себестоимости заказа

## Правило разделения

В одном документе показываются отдельно:

1. цена услуги клиенту;
2. стоимость материалов;
3. оплата работы маляру;
4. внутренняя себестоимость;
5. прибыль — только если все необходимые значения подтверждены.

ЛКМ не прибавляются к клиентской цене сверху, если нет отдельного правила пользователя. Во внутренней себестоимости фактическая стоимость ЛКМ учитывается отдельно.

## Подтверждённые ставки работы маляру

- Модерн — **6 000 тг/м²**.
- Выборка — **7 400 тг/м²**.
- Для других обработок: `нет данных`, пока пользователь не подтвердит ставку.

Для позиции `краска с 2х сторон` оплата услуги рассчитывается по удвоенной площади только этой позиции.
