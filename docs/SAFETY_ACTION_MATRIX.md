# SAFETY_ACTION_MATRIX

## SAFE

- answer text;
- create local report;
- update local state inside Hermes-Clean;
- dry-run;
- local test.

## CONFIRM_REQUIRED

- read external folders;
- read old archives;
- read Google Drive documents;
- run external API;
- work with tokens;
- connect Telegram.

## BLOCKED

- delete;
- modify old projects;
- modify real orders;
- launch live Telegram;
- move Drive files without approval;
- read `.env` / keys / tokens;
- change permissions;
- send files outward without approval.
