# План подключения телефона к Hermes-Clean

## Почему 127.0.0.1 на телефоне не работает

На Android-телефоне `127.0.0.1` = **сам телефон**, а не ПК.
Чтобы телефон открыл Mobile Web UI Hermes-Clean, нужно подключиться к IP ПК.

## Варианты подключения

### 1. Localhost Only (текущий) ✅

**Статус:** ВКЛЮЧЁН. Сервер на 127.0.0.1:8514. Только с этого ПК.

### 2. Same Wi-Fi / LAN 🚫

**Статус:** ВЫКЛЮЧЕН. Требует APPROVE_LAN_MODE.

Как работает:
- ПК и телефон в одной Wi-Fi сети
- Сервер слушает LAN IP (192.168.x.x)
- Телефон подключается к `http://192.168.x.x:8514`

Плюсы: просто, без VPN.
Минусы: порт открыт в локальной сети.

### 3. Tailscale / VPN 🚫

**Статус:** ВЫКЛЮЧЕН. Требует APPROVE_TAILSCALE_MODE.

Рекомендуемый первый вариант для телефона.

Как работает:
- Установить Tailscale на ПК и телефон
- Устройства получают IP в mesh-сети (100.x.x.x)
- Телефон подключается к Tailscale IP ПК

Плюсы: сквозное шифрование, не открывает порты на роутере.

### 4. USB Reverse Port Forward 🚫

**Статус:** ВЫКЛЮЧЕН. Для разработчиков.

```bash
adb reverse tcp:8514 tcp:8514
```

### 5. Публичный интернет ❌

**Статус:** PERMANENTLY BLOCKED. Никогда не включать.

## Pairing

Перед подключением телефона нужно pairing (привязка устройства).

Сейчас: **dry-run only** (mock-объекты, без реальных токенов).

Для реального pairing потребуется APPROVE_PHONE_PAIRING.
