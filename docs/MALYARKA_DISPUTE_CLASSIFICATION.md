# Malyarka Dispute Classification

## Назначение

Этот слой классифицирует спорные строки Malyarka только на синтетических данных внутри Hermes-Clean.

Он нужен для будущего безопасного сценария:

1. строка заказа разбирается;
2. подтверждённые строки идут в preview;
3. спорные строки получают категорию;
4. любая спорная строка блокирует финальное действие;
5. пользователь вручную подтверждает исправление.

## Категории

- `FORMAT_ERROR` — строка не соответствует формату `item | quantity | unit`.
- `MISSING_ITEM` — не указано название позиции.
- `INVALID_QUANTITY` — количество не число или не положительное.
- `MISSING_UNIT` — не указана единица измерения.
- `UNKNOWN_DISPUTE` — причина не распознана, нужна ручная проверка.

## Команда

```cmd
scripts\hermes.cmd malyarka-disputes
```

Команда создаёт локальный отчёт:

```text
05_REPORTS\MALYARKA_DISPUTE_CLASSIFICATION_REPORT.md
```

## Ограничения

- реальные заказы не читаются;
- клиентские документы не читаются;
- старые архивы не распаковываются;
- Google Drive не меняется;
- `.env`, токены и ключи не читаются;
- Excel-файлы не создаются;
- экспорт остаётся заблокированным до отдельного разрешения.
