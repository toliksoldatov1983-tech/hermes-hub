# Шаблон отчета по крупному блоку

Используй после каждого крупного блока работы.

```text
ВЫПОЛНЕНО:
- 

НЕ ВЫПОЛНЕНО:
- 

ИЗМЕНЁННЫЕ ФАЙЛЫ:
- 

ПРОВЕРКИ:
- 

РИСКИ:
- 

СЛЕДУЮЩИЙ КРУПНЫЙ БЛОК:
- 
```

## Правила заполнения

- Пиши только фактически выполненные действия.
- В `НЕ ВЫПОЛНЕНО` указывай ограничения, пропущенные действия и причины.
- В `ИЗМЕНЁННЫЕ ФАЙЛЫ` указывай только созданные или измененные файлы.
- В `ПРОВЕРКИ` указывай команды, ручные проверки или проверенные признаки.
- В `РИСКИ` указывай, что может повлиять на проект дальше.
- В `СЛЕДУЮЩИЙ КРУПНЫЙ БЛОК` всегда записывай один понятный следующий шаг.
