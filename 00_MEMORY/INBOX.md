# Входящие заметки

Здесь хранятся только временные мысли, черновики и задачи, которые ещё не стали правилом или частью проекта.

## Правила

- Стабильные сведения переносить в существующий тематический файл Hermes-Clean.
- Перед созданием новой заметки искать существующую, чтобы не создавать дубли.
- Завершённую работу фиксировать в `03_TASKS\DONE.md` и статусных файлах проекта.
- Секреты, токены, `.env`, данные клиентов и реальные заказы сюда не записывать.
