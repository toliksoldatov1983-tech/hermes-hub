# Безопасное чтение CorelDRAW CDR

Перенесено из [архив] [удалённый архив]: 2026-07-24.
Статус: справочный процесс. Для реального заказа требуется отдельное подтверждение.

## Назначение

Получить размеры объектов и площадь из файла CorelDRAW `.cdr`, не сохраняя и не изменяя исходный документ.

## Приоритетный способ

Использовать COM-автоматизацию CorelDRAW 2022:

- ProgID: `CorelDRAW.Application.24`;
- открыть документ в отдельном невидимом экземпляре;
- установить единицы документа в миллиметры;
- читать `Pages`, `Shapes.Count`, `SizeWidth`, `SizeHeight`;
- площадь одной стороны: `ширина × высота / 1 000 000`;
- закрыть документ без `Save`;
- завершить экземпляр CorelDRAW.

Терминал Hermes работает через bash. Для COM-команд PowerShell запускать явно через `powershell.exe -NoProfile -Command ...` или использовать Python с доступным COM-модулем.

## Проверка ZIP/ZCF

Некоторые `.cdr` CorelDRAW 2022 являются ZIP-контейнерами ZCF. Признаки:

- начало файла `PK`;
- тип `application/x-vnd.corel.zcf.draw.document+zip`.

Полезные внутренние файлы:

- `META-INF\metadata.xml` — страницы, объекты, размеры листа;
- `previews\page1.png` — визуальное превью;
- `content\*.dat` — бинарные данные объектов.

Распаковку выполнять только в отдельную временную папку и только после разрешения на доступ к конкретному реальному заказу.

## Контроль качества

- Сверить количество объектов в метаданных и `page.Shapes.Count`.
- Проверить превью страницы.
- Если ожидалось много деталей, а найден один объект, не додумывать: возможно, выбран другой файл или детали сгруппированы.
- Одна сторона и две стороны считаются отдельно.
- Торцы не включать без толщины и отдельного правила расчёта.

## Запреты

- Не вызывать `Save` или `SaveAs`.
- Не менять исходный `.cdr`.
- Не считать размеры листа размерами деталей.
- Не открывать реальный заказ без отдельного подтверждения пользователя.
