# MALYARKA CALCULATION RULES — IMPLEMENTED

Дата: 2026-07-04

---

## BIZ-014 — Тип заказа (обязательное поле)

Каждый заказ должен иметь признак «Тип заказа»:

| Значение | Маршрут | Выходные файлы |
|----------|---------|----------------|
| `paint_only` | Покраска | Excel Малярки + Финансы + Архив |
| `mill_and_paint` | Фрезеровка + покраска | Corel TXT + Excel Малярки + Финансы + Архив |

Если тип заказа не указан — заказ НЕКОМПЛЕКТНЫЙ.

## BIZ-008 — Группировка

Группа определяется сочетанием: **Материал + Толщина + Цвет + Тип обработки**

Пример:
```
Группа 1: МДФ 19 мм + RAL 9005 + модерн
Группа 2: МДФ 19 мм + RAL 9005 + выборка
```

Для каждой группы отдельно считаются: количество, квадратура, цена, расход.

## BIZ-021 — «Краска с 2х сторон»

Для строки с пометкой «краска с 2х сторон»:
- Расход краски ×2
- Расход грунта ×2
- Цена услуги ×2

Применяется ТОЛЬКО к указанной строке, не ко всему заказу.
