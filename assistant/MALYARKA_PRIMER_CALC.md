# MALYARKA PRIMER CALCULATOR

Дата: 2026-07-04 · Статус: **READY**

## Нормы грунта

| Тип обработки | Норма грунта |
|--------------|-------------|
| модерн | 300 г/м² |
| рифленка | 600 г/м² |
| выборка | 600 г/м² |

## Правила

- Грунт считается отдельно от краски
- Для «краска с 2х сторон»: грунт ×2
- В отчёте показывать: площадь → расход краски → расход грунта

## Пример

Заказ: 1.877 м², модерн, покраска
- Краска: 1.877 × 300 = 563 г
- Грунт: 1.877 × 300 = 563 г
- Итого ЛКМ: 1126 г
