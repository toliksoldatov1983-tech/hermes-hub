# FULL ASSISTANT ARCHITECTURE

## Главный принцип

Локальная база Hermes-Clean — главная. Google Drive — копия и архив.

## Сущности

| Сущность | Где хранится | Связи |
|----------|-------------|-------|
| Задача | `assistant/tasks/` | → Заказ |
| Заказ | `assistant/orders/` | → Расчёт, Экспорт |
| Клиент | в заказе | → Заказ |
| Расчёт | в заказе | → Цены, ЛКМ |
| Группа деталей | в заказе | → Расчёт |
| Файл экспорта | `E:\РАБОТА` | → Заказ |
| Отчёт | `05_REPORTS/` | → Заказ |
| Запись Google Drive | Drive | ← зеркало локального |

## Связи

```
Задача ──→ Заказ ──→ Расчёт ──→ Цены + ЛКМ
                │
                └──→ Экспорт ──→ E:\РАБОТА
                │
                └──→ Архивная карточка
                              │
Google Drive ←───────────────┘ (копия)
```

## Telegram

Принимает: заказы, статус, «что дальше»
Не управляет задачами (десктоп — основной интерфейс)
