# PROJECT_RULES

## Источник правды

Только `C:\Users\user\Desktop\прайсы\Hermes-Clean`.

## Архивные источники

- `«Гермес Клин».zip [архив]`
- `[архив] архивный zip-файл`
- `[удалён]`
- старые Google Drive документы

Они не используются как рабочая правда без проверки и разрешения.

## Безопасные локальные действия

- создавать и менять файлы внутри Hermes-Clean;
- создавать локальные планы и отчёты;
- создавать код-каркас;
- запускать локальные тесты без внешних сервисов;
- создавать dry-run интерфейсы;
- создавать `.env.example` без реальных ключей.

## Запрещено без approval gate

Удаление, изменение Google Drive файлов, чтение секретов, live Telegram, реальные заказы, изменение старых проектов, распаковка архивов как рабочих проектов.
