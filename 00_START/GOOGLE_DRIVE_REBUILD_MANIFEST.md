## Порядок заполнения после очистки Drive

1. Восстановить OAuth только для `drive,docs,sheets`.
2. Выполнить read-only проверку, что Drive действительно пуст или содержит только системно недоступные объекты.
3. Создать корневую папку `МАЛЯРКА — УПРАВЛЕНИЕ` и шесть категорий `00`–`05`.
4. Создать 16 Google-документов из канонических Markdown-файлов по этому манифесту.
5. Создать главный индекс со ссылками на загруженные документы.
6. Проверить количество файлов, названия, права доступа и отсутствие дублей.
7. Не предоставлять общий доступ без отдельного подтверждения пользователя.
