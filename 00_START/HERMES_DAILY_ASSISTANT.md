# HERMES DAILY ASSISTANT — MVP Base

Утренний план и вечерний отчёт. Без внешних действий.

---

## Утренний план (Morning Briefing)

Запуск: команда или фраза «план на сегодня».

**Что показывает:**
- Сегодняшняя дата
- Текущий статус всех линий
- Активные заказы Malyarka
- Просроченные задачи
- Риски и предупреждения
- Что можно сделать быстро
- Вопрос: «Что сегодня главное?»

**Формат:**
```
📅 СЕГОДНЯ — 03.07.2026
━━━━━━━━━━━━━━━━━━━━━
Malyarka: READY_FOR_NEXT_REAL_ORDER
Telegram: DRY-RUN CLOSED
E:\РАБОТА: connected ✅
Tests: 809 passed

Заказы в работе:
  Иван фасады — CLOSED ✅

Риски:
  Нет активных рисков

Быстрые действия:
  /order — новый заказ
  /status — полный статус
  /next — что дальше

Что сегодня главное?
```

---

## Вечерний отчёт (Evening Report)

Запуск: команда или фраза «отчёт за день».

**Что показывает:**
- Что сделано за день
- Что не сделано
- Что перенести на завтра
- Ошибки и выводы
- Решения для сохранения в память
- Следующий шаг на завтра

**Формат:**
```
🌙 ОТЧЁТ ДНЯ — 03.07.2026
━━━━━━━━━━━━━━━━━━━━━
Сделано:
  • MVP Base запущен
  • Backup создан
  • UI команды описаны

Не сделано:
  • —

На завтра:
  • Ждать следующий заказ
  • Черновик цен/склада

Ошибки:
  • Нет

Память:
  • Сохранить roadmap в /learn
```

**Запрещено:** автоматические внешние действия, отправка сообщений.
