# MASTER_PROJECT_PLAN

## Цель

Hermes-Clean — новый чистый ежедневный помощник пользователя и новый источник правды проекта.

Проект не ремонтирует старый хаос Hermes / Malyarka. Старые архивы, старые Google Drive документы и карантинные папки считаются только архивными источниками после проверки.

## Основные решения

- Hermes-Clean — отдельный новый проект.
- Старые `«Гермес Клин».zip [архив]` и `[архив] архивный zip-файл` не являются рабочим проектом.
- Старые Google Drive документы не являются актуальной правдой.
- Malyarka — отдельный модуль внутри Hermes, а не весь Hermes.
- Gemini — основной будущий AI-провайдер.
- DeepSeek / DeepSig — fallback или review-провайдер.
- Codex пишет код.
- Внешний AI-review не редактирует проект напрямую.
- Telegram сначала работает только в dry-run.
- Live Telegram включается только после `APPROVE_TELEGRAM_LIVE`.

## Approval gates

Все опасные действия выполняются только после отдельного разрешения пользователя.

Текущий Drive-перенос заблокирован `403 appNotAuthorizedToFile` и переведён в pending approvals.
