# GOOGLE_DRIVE_CLEANUP_PLAN

## Блок

BATCH_005_PREPARE_GOOGLE_DRIVE_CLEANUP_PLAN

## Цель

Подготовить безопасный план очистки Google Drive по Hermes / Malyarka.

На этом этапе Google Drive не изменяется: ничего не удалять, не перемещать, не переименовывать, не менять права доступа и не менять синхронизацию.

Google Drive содержит много старых Hermes / Malyarka документов, часть из них может быть ошибочной или устаревшей.

Нужно отделить новое чистое пространство от старого архива.

Старые Google Drive файлы не считаются актуальной правдой проекта.

## Главные источники

`«Гермес Клин».zip [архив]` и `[архив] архивный zip-файл` на рабочем столе остаются главными архивными источниками.

Старые Google Drive документы не являются главным источником.

Информацию из Google Drive можно переносить в Hermes-Clean только после проверки и отдельного решения.

## Будущая структура Google Drive

### HERMES_CLEAN

Будущая папка для чистого актуального пространства.

Сюда должны попадать только:

- новые чистые документы;
- актуальные файлы Hermes-Clean;
- подтверждённые правила;
- новые отчёты;
- новые инструкции Codex;
- файлы, созданные после начала чистой пересборки.

### HERMES_OLD_ARCHIVE

Будущая папка для старых архивных документов.

Сюда позже можно переносить только после утверждения пользователя:

- старые документы Hermes;
- старые документы Malyarka;
- старые планы;
- старые отчёты;
- старые Google Docs;
- старые инструкции;
- старые ошибочные или сомнительные файлы.

## Категории Google Drive файлов

### А. ОСТАВИТЬ В HERMES_CLEAN

- новые файлы Hermes-Clean;
- подтверждённые правила;
- новые отчёты;
- новые инструкции Codex;
- актуальные документы по новой сборке.

### Б. ПЕРЕНЕСТИ В HERMES_OLD_ARCHIVE ПОЗЖЕ

Только после инвентаризации и отдельного утверждения пользователя:

- старые `HERMES_*.md`;
- старые `TELEGRAM_SETUP_RU.md`;
- старые `QUICK_START_RU.md`;
- старые `daily_agent_log.md`;
- старые `2026-*.md`;
- старые файлы цен;
- старые proposal-файлы;
- старые тестовые документы;
- старые документы по Малярке, если они не подтверждены заново.

### В. НЕ ТРОГАТЬ БЕЗ ОТДЕЛЬНОГО РАЗРЕШЕНИЯ

- личные документы;
- документы не по Hermes / Malyarka;
- файлы с доступами;
- файлы с токенами;
- файлы с ключами;
- документы реальных заказов;
- документы клиентов;
- Google Sheets с рабочими данными;
- любые неизвестные файлы.

### Г. ТРЕБУЕТ ПРОВЕРКИ

- документы с непонятным названием;
- документы без явной связи с Hermes;
- старые выжимки;
- старые отчёты;
- файлы, где может быть полезная информация, но нельзя считать её актуальной.

## Будущий порядок очистки Google Drive

1. Сначала составить список видимых Google Drive файлов и папок по Hermes / Malyarka.
2. Разнести найденные элементы по категориям: HERMES_CLEAN, HERMES_OLD_ARCHIVE, НЕ ТРОГАТЬ, ТРЕБУЕТ ПРОВЕРКИ.
3. Показать список пользователю.
4. Получить отдельное разрешение пользователя на любые изменения.
5. Только после разрешения создать или использовать папки `HERMES_CLEAN` и `HERMES_OLD_ARCHIVE`.
6. Переносить только утверждённые элементы.
7. Ничего не удалять.
8. Спорные документы оставлять на месте.
9. После любых будущих изменений создать отдельный отчёт.

## Запреты

- Не удалять Google Drive файлы.
- Не перемещать Google Drive файлы без отдельного разрешения.
- Не менять права доступа.
- Не создавать папки на Google Drive без разрешения.
- Не менять синхронизацию Google Drive.
- Не трогать личные документы.
- Не трогать документы клиентов.
- Не читать токены, ключи и `.env`.
- Не запускать старый Hermes.
- Не распаковывать архивы.

## Итог BATCH_005

План очистки Google Drive подготовлен локально внутри Hermes-Clean.

Google Drive не изменялся.
