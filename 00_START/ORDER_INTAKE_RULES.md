# ПРАВИЛА ПРИЁМА ЗАКАЗА

Дата: 2026-07-04 · Источник: Google Drive + «Гермес Клин»

---

## 1. Некомплектный заказ

Заказ неполный если нет:
- тип заказа (покраска / фрезеровка + покраска)
- имя заказчика
- дата
- размеры
- материал
- толщина
- цвет
- тип обработки

Пока поля не заполнены — заказ не переходит в чистовой вид.

## 2. Спорная строка

Строка → спорная если:
- неясно прочитана цифра
- неясен размер
- неясно количество
- неясен материал
- неясна толщина
- неясен цвет
- неясен тип обработки

Рукописные цифры, прочитанные неуверенно → сразу в спорные.

## 3. Правило «не додумывать»

- Неуверенная цифра или размер → в спорные строки
- Пока есть спорные строки запрещено: считать итог, квадратуру, цену, расход
- Запрещено делать чистовой документ при любых спорных строках

## 4. Формат спорных строк

- Выдаются текстом для копирования
- Пользователь копирует → исправляет → вставляет в чат
- После исправления весь заказ пересчитывается заново

## 5. Порядок размеров

- Первое число — высота
- Второе — ширина
- Третье — количество
- Нет количества = 1 штука

## 6. Маршруты и группы

- Покраска или фрезеровка + покраска
- Группа = материал + толщина + цвет + тип обработки

## 7. Запрещено

- Выдумывать цифры
- Обещать сроки
- Добавлять поля и блоки без согласования
- Делать улучшения самовольно

## 8. Сохранение скриншотов клиента

- При первом получении скриншотов — сохранять в папку заказа `client_originals/`
- Если заказ не завершён — при возврате читать сохранённые, не просить заново
- В архивной карточке хранить оригиналы как доказательство источника цифр
