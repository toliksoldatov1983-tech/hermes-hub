# HERMES GLOBAL ROADMAP — 11 этапов

## Этап 1: Зафиксировать карту проекта

- **Цель:** Полная инвентаризация всех направлений
- **Сделать:** GLOBAL_PROJECT_INVENTORY.md
- **Запрещено:** Менять production-код
- **Stop:** —
- **Результат:** Карта 18 направлений готова ✅

## Этап 2: Чистка Hermes без удаления важного

- **Цель:** Освободить место, убрать дубликаты
- **Сделать:** Аудит сессий, dedup memory, cleanup staging
- **Запрещено:** Удалять без backup
- **Stop:** Если нужен delete/reset
- **Результат:** Чистая система, меньше шума

## Этап 3: Backup + GitHub

- **Цель:** Защита от потери данных
- **Сделать:** GitHub auth, backup config+skills+staging, первый push
- **Запрещено:** Push без approval, push токенов
- **Stop:** Если нет GitHub auth
- **Результат:** Код и конфиг в безопасности

## Этап 4: Obsidian memory

- **Цель:** Связка Hermes memory ↔ Obsidian vault
- **Сделать:** Read-only чтение vault, авто-заметки
- **Запрещено:** Удалять/менять заметки пользователя
- **Stop:** Если vault недоступен
- **Результат:** Заметки Obsidian доступны Hermes

## Этап 5: Ежедневник / daily assistant

- **Цель:** Утренний отчёт, план дня, напоминания
- **Сделать:** Cron-based daily report, статус всех линий
- **Запрещено:** Спамить, слать без approval
- **Stop:** Если нет канала доставки
- **Результат:** Автоматический daily briefing

## Этап 6: Vision dry-run

- **Цель:** Распознавание скриншотов заказов
- **Сделать:** Тестовый прогон на учебном скриншоте
- **Запрещено:** Читать реальные заказы через vision
- **Stop:** Если нужен API key
- **Результат:** Vision готов к controlled тесту

## Этап 7: Telegram controlled integration

- **Цель:** Первый контролируемый live Telegram
- **Сделать:** Approval → token → single-user polling test
- **Запрещено:** Массовые сообщения, группы, webhook
- **Stop:** Без approval-фразы
- **Результат:** Telegram-бот работает для 1 пользователя

## Этап 8: Голос / Джарвис

- **Цель:** Wake word + голосовое управление
- **Сделать:** Wake word detection, голосовые команды
- **Запрещено:** Continuous listening без privacy policy
- **Stop:** Если нет микрофона
- **Результат:** «Салам Гоголь» → Джарвис отвечает

## Этап 9: Цены / склад / расчёты

- **Цель:** Автоматический расчёт стоимости заказа
- **Сделать:** Калькулятор м² + материал + работа, складской учёт
- **Запрещено:** Менять production-заказы без approval
- **Stop:** Если нет цен от пользователя
- **Результат:** Смета к каждому заказу

## Этап 10: Мобильный доступ

- **Цель:** Доступ к Hermes с телефона
- **Сделать:** Tailscale/LAN controlled access, mobile UI
- **Запрещено:** Открывать наружу без VPN
- **Stop:** Без approval
- **Результат:** Заказы с телефона

## Этап 11: Google Drive (только после безопасного плана)

- **Цель:** Резервное копирование в облако
- **Сделать:** План безопасности, controlled upload
- **Запрещено:** Авто-синхронизация, upload без approval
- **Stop:** Всегда — до отдельного плана
- **Результат:** Безопасный backup в Drive
