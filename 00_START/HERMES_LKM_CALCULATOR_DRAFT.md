## 4. OVERRIDE НА УРОВНЕ ЗАКАЗА

В конкретном заказе можно вручную изменить расход:

```
Заказ: Иван фасады v2
Материал: PGP301
Профиль: MODERN
Расход по норме: 300 г/м²
Override: нет (используем норму)
```

---

## 5. ПРАВИЛА ПОВЕДЕНИЯ HERMES

- Нашёл профиль → считаю по норме
- Не нашёл профиль → **спрашиваю пользователя**, не придумываю
- Пользователь дал override → использую его
- Новый материал/профиль → добавляю в таблицу как draft
- Ничего не hardcode
