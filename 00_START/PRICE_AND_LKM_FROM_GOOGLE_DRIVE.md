## Правила ценообразования (BIZ-015/016/017)

- Цена НЕ зависит от толщины МДФ
- Цвет влияет только: VLUX (клиент оплачивает сам) + мелкий заказ с покупкой краски
- Без VLUX и без спецзакупки — цвет цену не меняет
- Цена = Тип заказа + Тип обработки
- «Краска с 2х сторон»: расход ×2, грунт ×2, услуга ×2 (только для этой позиции)
